# ai-theories.github.io

The root GitHub Pages site for the ai-theories organization. Search engines read `robots.txt` only at the root of a host, and AI tools look for `llms.txt` there, so this repository publishes both for every project under `ai-theories.github.io`:

- `robots.txt` allows crawling and lists each project's sitemap
- `llms.txt` links to each project's own `llms.txt`
- `index.html` links to the projects

Projects: [Wealth Skills](https://github.com/ai-theories/wealth-skills), published at https://ai-theories.github.io/wealth-skills/.
